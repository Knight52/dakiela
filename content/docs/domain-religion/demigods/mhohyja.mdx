### Info

โมท์ไฮจา (Mhohyja) คือ มนุษย์ผู้ที่ได้รับพลังจากเทพหลายองค์ ได้แก่ [ซารีนธาล
(Saryntaal)](../greater-gods/saryntaal), [เฟล (Fel)](../greater-gods/fel), [โคเด็กซ์ (Codec)](../greater-gods/codec), [เวอร์ซาเอล (Versael)](../greater-gods/versaal), และ [ฟาร์คินน์
(Farkin)](../greater-gods/farkin) ถึงจะเล็กน้อยแต่เหล่าเทพต่างอวยพรจนมีอีกนามว่า "ผู้เป็นที่รัก"
ความงดงามของโลกใบนี้คือท่านและท่านนั้นก็คือความงดงาม
ผู้ใดที่ได้แตะต้องกับเพียงเส้นผมของท่านก็จะมีสามารถที่เปลี่ยนแปลงชะตาได้เลย

### Description
โมท์ไฮจา (Mhohyja) มีลักษณะเป็นมนุษย์วัยเยาว์ผู้งดงามและอ่อนช้อย
ไม่สามารถล่วงรู้ได้ว่าป็นหญิงหรือชาย ผิวขาวกระจ่าง ดวงตาเวววาวราวอัญมณี ในหน้าราวตุ๊กตา
และผมสีแทงอันเงางาม

### Personality

โมท์ไฮจา (Mhohyja) มีนิสัยรักสนุกแต่ก็ยังถือตน ผู้คนที่กล่าวชมและนับถือจะสามารถคงอยู่ได้
โดยส่วนผู้ที่หันหลังให้จะไม่ได้รับความดูแลใยดีใด
ท่านมักจะโผล่มาเยี่ยมชมให้กับหญิงสาวที่กำลังจะสูญเสียพรหมจรรย์หรือเด็กน้อยที่พึ่งเกิดแบบเงียบๆ
เพื่อดูว่าคนผู้นั้นควรได้รับการอวยพรหรือไม่
ซึ่งในความเป็นจริงแล้วมีเพียงผู้คนเพียงหยิบมือจะได้รับการอวยพร

### Relationships

โมท์ไฮจา (Mhohyja)
ชื่นชอบเทพทุกองค์ให้เกียรท่านแต่ท่านไม่ชอบผู้ที่มีความสวยงามมากกว่าตนเอง
โดยท่านจะไม่ยอมโผล่มาเคียงข้างเทพรูปลักษณ์สตรีองค์อื่นเด็ดขาด

### Worshipers

เหล่าเด็กน้อยและหญิงสาวที่เกิดมาในบ้านมีฐานะดีมักจะถูกสอนให้นับถือและบูชา โมท์ไฮจา
(Mhohyja) จนกว่าจะได้เจอคู่ครอง
เพราะเชื่อกันว่าจะทำให้ชีวิตพบเจอกับโชคชะตาที่ดีโดยไม่มีคนไหนที่ไม่รู้จักท่าน
เหล่าสตรีผู้ศรัทธาส่วนใหญ่จะไว้ผมยาวพร้อมดูแลมันอย่างเอาใจใส่และประณีต
พวกเขาต่างภาวนาผ่านเส้นผมของตนเองเพื่อยังคงความเยาว์วัยเอาไว้
แม้นักแสดงส่วนใหญ่จะนับถือ [เฟโรโมเดียส (Pheromodias)](./Pheromodias)
แต่ก็ปฏิเสธไม่ได้ว่าในบางครั้งก็ทำการงภาวนาต่อ โมท์ไฮจา (Mhohyja)
เพื่อเป็นที่จับตามองและรักษาจุดโดดเด่นของตนเองไว้
ซึ่งทำให้ผู้ศร้ทธาทั้งหมดนี้จะให้ความสำคัญต่อผมยาวสลวยของตนเป็นอย่างมากที่สุดไม่ต่างกับอวัยวะนึงของร่างกาย

### สัญลักษณ์

สัญลักษณ์ของ โมท์ไฮจา (Mhohyja) จะเป็นวงแหวนที่ซ้อนทับกันไปมาอย่างสวยงาม
โดยมักจะปักด้ายสัญลักษณ์ลงบนเสื้อผ้าที่สวมใส่ในจุดที่สามารถเห็นได้ ซึ่งเชื่อว่าได้รับการอวยพรจาก
โมท์ไฮจา (Mhohyja) แต่จำเป็นต้องเป็นด้ายสีทองเท่านั้นและต้องสวยงาม
ไม่อย่างนั้นอาจจะถูกสาปแทน


### History

โมท์ไฮจา (Mhohyja) คือผู้ที่เกิดมากับความงดงามแต่กลับถูกโชตชะตากลั่นแกล้งให้เป็นคนยากจน
ทั้งชีวิตต้องดิ้นรนต่อสู้จนเกือบจะสูญเสียความเป็นมนุษย์ แต่ที่น่ายกย่องคือ
หลักการใช้ชีวิตนั้นเป็นไปตามบัญญัติของเทพถึงห้าองค์อย่างไม่มีความบกพร่อง
ความสวยงามที่ดิ้นอยู่บนโชคชะตาอันเน่าแฟะหลังจากนั้นจึงได้รับพรจากเหล่าเทพเพื่อจุดติใหม่และกลายเป็นสิ่งที่เต้นรำอยู่บนเส้นด้ายแแห่งโชคชะตา
