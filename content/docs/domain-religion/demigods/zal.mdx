### Info

ซอล (Zal) คือ เซนทอร์ผู้ที่ได้รับพลังจาก [เกนต์ (Ghent)](../greater-gods/ghent) พร้อมกับ [เนเมสส์ (Nemes)](../greater-gods/nemes)
เขาเริ่มจากการล่าทีละอย่างและมากขึ้นไปเรื่อยเพื่อเติมเต็มคำสั่งของ [Greater God](../greater-gods)
ที่เป็นเหมือนภารกิจหลักของเขา
โดยแนวคิดหลักคือการล่าเพื่อมีชีวิตรอดและล่าสิ่งมีชีวิตที่ต้องถูกกำจัดทิ้งเพื่อความสุขสบายของส่วนรวมด้วยคันศรแห่งแสงสีทอง

### Description
ซอล (Zal)
มีลักษณะเป็นเซนทอร์เกราะสีทองที่เปราะเปื้อนไปด้วยดินจากการทำงานหนักและการเดินตรวจสภาพแวดล้อม
อาวุธประจำตัวจะเป็นคันศรแสงสีทองที่ [เนเมสส์ (Nemes)](../greater-gods/nemes)
มอบให้โดยจะสามารถเรียกออกมาเมื่อไหร่ก็ได้ตามใจนึกและยิงได้ไม่จำกัดตราบที่เขาต้องการ

### Personality

ซอล (Zal) จะเป็นพวกพูดน้อยแต่ฟังทุกสิ่งที่เกิดขึ้นและตอบเท่าที่ต้องตอบ
การคิดเองของเขาจะทบทวนตัวเองหลายเงื่อนไขเหมือนกับการเตรียมตัวของเหล่านักล่าก่อนตัดสินใจลงมือ
โดยมีข้อแม้ว่าถ้าตัดสินใจว่าต้องทำแล้วเขาจะค่อยลงมือทำตามที่สมควร

### Relationships

ซอล (Zal) มีความสัมพันธ์เป็นกลางต่อ [Greater God](../greater-gods) ทุกตนและไม่ค่อยถูกคอกับ [เฟโรโมเดียส
(Pheromodias)](./pheromodias) เพราะการล่าของเขาไม่ได้เป็นการสร้างศิลปะขึ้นมาเพื่อเป็นเรื่องราว
แต่เป็นการล่าเพื่อสร้างจุดจบและไม่ชอบเรื่องราวที่สร้างเพื่อความสนุกสนานจากความตายที่ควรเกิดขึ้นอย่างถูกต้อง

### Worshipers

สัญลักษณ์ของ ซอล (Zal) จะเป็นเป้าเล็งที่เป็นรูปดวงอาทิตย์แห่งการตัดสินในการเล็งของเค้า
